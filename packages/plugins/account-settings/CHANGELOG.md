# Changelog

## 0.1.0-alpha.2

- 账号菜单在「设置」与「退出登录」之间新增「检查更新」：`/api/auth/me` 返回 `desktop: true` 时显示，点击经 `workdsh://check-update` 窄通道通知桌面载体（与托盘「检查更新」同一路径）；浏览器形态不显示该项。

## 0.1.0-alpha.1

- 新增侧栏底部个人账号入口：注册官方 `settings.launcher` 槽位，显示登录账号头像与姓名。
- 账号菜单提供「设置」（打开官方设置弹窗）与「退出登录」（二次确认后调用同源 `/api/auth/logout`）。
- 账号菜单在账号与退出登录之间新增「插件广场」，触发第三方 SkillHub 的广场浮层；该插件未安装时不显示此项。
- `/api/auth/me` 不可用时入口退化为「设置」，菜单只保留设置项与插件广场项。
