# CHANGELOG

## 0.1.0-alpha.1

- 新增设置「模型市场」页：授权模型列表、筛选分页、模型详情、安装/卸载。
- Host 侧安装到官方 `llm-pi-ai`：按供应商/协议/地址/密钥聚合路由，写入官方凭据存储。
- 默认模型首次自动安装并写入 `agent-default-model`；用户卸载后不再自动恢复。
- 安装/卸载结果通过统一的资产操作记录接口上报（`assetType=model`），为尽力而为，不阻断本机安装结果。
- 模型详情页按后台新增字段重排：供应商/标识/版本/类型改为标签，新增默认模型、输入类型、标签、描述、最大输出 token、订阅数、发布时间与 API 协议，并在开启推理等级时展示档位表（固定列宽）。
