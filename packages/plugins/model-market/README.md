# 模型市场

设置中的独立「模型市场」页：读取后台已授权模型，安装到本机官方 `llm-pi-ai` 路由，并写入凭据。

## 公开入口

| 入口 | 职责 |
| --- | --- |
| 根入口 | Host 服务 `workdshModelMarket`：市场查询、安装、卸载、默认模型种子与后台上报 |
| `./client` | 在官方 `settings.section` 注册「模型市场」页，紧跟官方「模型」；并接管 `conversation.input.model` 座位渲染会话模型选择器 |

## 页面

- 列表页：关键词（名称/说明）、供应商、模型类型、API 协议、仅看默认、分页。
- 详情页：图标与名称、安装状态与安装/卸载按钮、供应商/模型标识/版本/模型类型标签、默认模型与输入模态标签、业务标签、模型描述，以及上下文长度、最大输出 token、负责人、负责部门、订阅数、发布时间、API 协议、是否开启推理等级；开启推理等级时按后台 `reasoningLevels` 展示档位、API 参数值、描述与消耗速度倍率。
- 自定义模型：新增「添加自定义模型」页内表单（Provider ID、显示名称、API 地址、协议、密钥、模型目录、设为默认），安装后进入「本地自定义」分组，可在此查看和卸载。
- 状态：`语音识别 / 向量模型 / 重排序模型` 与 `自定义 HTTP / gRPC` 展示但不可安装。
- 会话模型选择器（`src/client/model-select/`）：Auto 开关、快速 / 均衡 / 极致三档、按 provider 分组的模型列表、悬停右侧二级详情（描述 / 消耗倍率 / 繁忙程度 / 思考强度 / 上下文窗口）、底部「模型管理」入口。点击「模型管理」只跳转「设置 → 模型管理」分区，不带任何预置动作（`src/client/settings-nav.ts` 负责分区跳转）。具体模型与思考强度真实调用官方 `select()`；Auto 与三档为展示态（灰化、悬浮查看说明、不可选中），档位真实调度待后端网关，见 `specs/model-selector/backend-todos.md`。

## 安装规则

- 安装状态以本机配置为准；安装/卸载结果统一实时上报到资产操作记录接口（`assetType=model`），上报失败不阻断本机结果。
- 分组键为 `provider + apiProtocol + apiUrl + apiKey`，同组模型聚合到一条 `workdsh-*` provider。
- 安装写官方 `llm-pi-ai` 配置与官方凭据存储；接口返回的 `apiKey` 只在 Host 内使用，不下发渲染层。
- 自定义模型由用户填写完整配置，Host 校验后同样写入 `llm-pi-ai` 与凭据；卸载时删除整条自定义路由，不上报后台。
- `isDefault=1` 的模型自动安装并写入 `agent-default-model`：每个默认模型只处理一次，之后即使后台改了该模型的接口或密钥也不会覆盖本地，只安装新增的默认模型。
- 用户卸载默认模型后记录为已忽略，不再自动装回。
- 安装记录与完成标记按账号隔离；Desktop 首次登录时过场页等待完成标记（最长 15 秒），超时放行后由后台补齐，之后每次启动后台静默处理。
- 卸载默认模型时撤销 `agent-default-model` 的用户层覆盖。

## 边界

- 官方模型页与路由仍由官方 DSH 拥有；**会话输入框的模型选择器经用户显式授权（2026-11-18）由本插件接管**：通过公开 `conversation.input.model` 插槽以更低 `priority` 遮蔽官方 `ModelSelect`，复用官方 `ModelSelectInjected` 注入面（`available / directory / load / select`），不修改任何官方文件。
- 该选择器中的 Auto、快速 / 均衡 / 极致三档、消耗倍率、促销标签、繁忙程度为**展示态**；真实档位调度与判档待后端网关，倍率 / 标签 / 上下文来自 `src/client/model-select/meta.ts` 的本地映射与确定性兜底。
- 删除本插件后市场页与自定义选择器一起消失，官方模型选择器原样回归；已安装的 provider 仍是普通官方模型配置。
