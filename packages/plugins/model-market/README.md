# 模型市场

设置中的独立「模型市场」页：读取后台已授权模型，安装到本机官方 `llm-pi-ai` 路由，并写入凭据。

## 公开入口

| 入口 | 职责 |
| --- | --- |
| 根入口 | Host 服务 `workdshModelMarket`：市场查询、安装、卸载、默认模型种子与后台上报 |
| `./client` | 在官方 `settings.section` 注册「模型市场」页，紧跟官方「模型」 |

## 页面

- 列表页：关键词（名称/说明）、供应商、模型类型、API 协议、仅看默认、分页。
- 详情页：模型信息、标签、说明、安装配置、安装/卸载。
- 自定义模型：新增「添加自定义模型」页内表单（Provider ID、显示名称、API 地址、协议、密钥、模型目录、设为默认），安装后进入「本地自定义」分组，可在此查看和卸载。
- 状态：`语音识别 / 向量模型 / 重排序模型` 与 `自定义 HTTP / gRPC` 展示但不可安装。

## 安装规则

- 安装状态以本机配置为准；`useModel` / `unUseModel` 只做后台上报，失败不阻断本机结果。
- 分组键为 `provider + apiProtocol + apiUrl + apiKey`，同组模型聚合到一条 `workdsh-*` provider。
- 安装写官方 `llm-pi-ai` 配置与官方凭据存储；接口返回的 `apiKey` 只在 Host 内使用，不下发渲染层。
- 自定义模型由用户填写完整配置，Host 校验后同样写入 `llm-pi-ai` 与凭据；卸载时删除整条自定义路由，不上报后台。
- `isDefault=1` 的模型首次启动自动安装，并写入 `agent-default-model`；用户卸载后记录为已忽略，不再自动装回。
- 卸载默认模型时撤销 `agent-default-model` 的用户层覆盖。

## 边界

- 官方模型页、模型选择器与路由仍由官方 DSH 拥有；本插件只新增一个设置分区。
- 删除本插件后市场页消失，已安装的 provider 仍是普通官方模型配置。
