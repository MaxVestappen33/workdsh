1. 当我说打包给莱阳用时，需要将workdsh-app.json中的server.baseUrl设置为http://56.88.100.117:18080/ytsj-ai，server.adminSsoUrl设置为http://56.88.100.117:3009/clientSSO，最终的安装包后追加laiyang标识，比如PoliceAssistant-1.0.2-x64-Setup-laiyang.exe
2. 当我说打包给本地用时，需要将workdsh-app.json中的server.baseUrl设置为http://127.0.0.1:18080/ytsj-ai，server.adminSsoUrl设置为http://localhost:3100/clientSSO，最终的安装包后追加local标识，比如PoliceAssistant-1.0.2-x64-Setup-local.exe
3. 当我说打包给市局用时，需要将workdsh-app.json中的server.baseUrl设置为http://56.82.4.232:18080/ytsj-ai，server.adminSsoUrl设置为http://56.82.4.232:3100/clientSSO，最终的安装包后追加yantai标识，比如PoliceAssistant-1.0.2-x64-Setup-yantai.exe
4. 打包一定要使用最新的代码进行打包，不能使用旧的代码进行打包。
5. 所有涉及到/ytsj-ai/desktop-client的后台api接口，统一维护在app-config.ts文件的APP_CONFIG_DEFAULTS变量中的server中。
6. 启动项目时如果没有指定版本启动，要以最新代码为准启动，不能使用旧的代码启动。
7. 当我说打信创包时，是指打包 Linux arm64 的 deb 安装包，打包流程为：先构建 apps/web（`corepack pnpm install --frozen-lockfile && corepack pnpm build`），再重新生成 Profile 打包清单（先删除 apps/desktop/build/workdsh-profile-release，再执行 `node apps/desktop/scripts/pack-workdsh-profile.mjs apps/web`），最后在 apps/desktop 目录执行 `corepack yarn dist:linux`（本机需带环境变量 NODE_OPTIONS=--use-system-ca、ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/、ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/）。产物在 apps/desktop/dist/linux/arm64/ 目录，命名为 PoliceAssistant-<版本号>-arm64.deb，按目标环境追加标识，比如 PoliceAssistant-1.0.3-arm64-laiyang.deb。
